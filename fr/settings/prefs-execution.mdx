Combien d’historique vos rapports lisent, et comment ils montrent les suites — **Mes préférences › Exécution**.

- **Runs analysés au plus** — les plus anciens au-delà sont ignorés. Quand le projet ou le profil du plan impose la valeur, elle se lit avec son cadenas ; sinon vous choisissez entre 100, 200, 500 ou 1 000.
- **Suites vides** — **Afficher les suites vides** montre les suites sans aucun point de test dans le plan.

La pondération du taux de réussite n’est plus ici : elle est dans **Seuils et calculs**.

## Runs analysés par cas de test {#max-runs}

Au-delà de 200, la génération ralentit sur les grands plans, et la page vous prévient.

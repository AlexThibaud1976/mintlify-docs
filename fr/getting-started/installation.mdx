TestPulse Studio est une extension gratuite du Visual Studio Marketplace. Elle est privée pour l’instant : elle est partagée avec les organisations à qui elle est destinée et n’apparaît pas dans une recherche du Marketplace.

## Depuis le Marketplace {#marketplace-install}

1. Ouvrez la page de l'extension depuis le lien reçu, ou depuis **Paramètres de l’organisation › Extensions › Partagées**
2. Cliquez sur **Obtenir gratuitement**
3. Sélectionnez votre **organisation**
4. Cliquez sur **Installer** et acceptez les scopes de permission
5. Ouvrez un projet : le groupe **TestPulse Studio** apparaît dans la navigation du projet, avec ses quatre espaces **Insights**, **Coverage**, **Design** et **Tools**

## On-premise (.vsix) {#onprem-install}

1. Ouvrez la page de l'extension depuis le lien reçu, cliquez sur **Obtenir gratuitement**, puis sur **Télécharger** (proposé pour Azure DevOps Server) pour obtenir le `.vsix`
2. Allez dans **Collection Settings → Extensions → Manage Extensions**
3. Cliquez sur **Upload extension** et sélectionnez le fichier `.vsix`
4. Cliquez sur **Installer** pour le rendre disponible dans tous les projets

## Prérequis {#prerequisites}

| Prérequis | Détails |
| --- | --- |
| Version Azure DevOps | Azure DevOps Services (cloud). Azure DevOps Server 2022.1 : vérification en cours (l'extension s'installe sur Server) |
| Navigateur | Chrome, Edge ou Firefox avec JavaScript activé |
| Permissions | Membre d'un projet avec au moins un plan de test |
| Admin (install uniquement) | Admin organisation pour installer les extensions |

What the administrators have set for the whole project, for the **selected plan** (or the project default when no plan is selected) — **My preferences › Project rules**. Read only: to change something, contact a project administrator. Every line gives its value and its **provenance** (profile, project, project default, each member, shipped value).

- **Verdict and reports** — the quality scoring, the success threshold, the bugs taken into account, the promotion decision, the branding, the report sections.
- **Test grid** — what the report expects from this plan (a missing type raises a point of attention, with no effect on the verdict), the catalogue (levels, types, objectives, detected by tag, suite, area path then title), the default design and, when it is on, the requirement assessment.
- **AI assistant** — the state, the provider and the model, the functions open for the plan (and those a profile turns off), the data sent to the model, the access mode. Configured does not guarantee that a call will succeed for your account. With an API key, the page says it plainly: the key is hidden on screen but remains reachable by any project member with developer tools.

A project administrator gets a single **Open the administration** button; anyone else reads **Reserved for project administrators**. On a project with no configuration yet, the shipped values apply and each member sets their own — the scoring, the bug source, the promotion decision and the AI assistant remain shared by the whole project.

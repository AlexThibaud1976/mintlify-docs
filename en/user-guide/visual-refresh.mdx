TestPulse Studio has a **new visual identity** — a teal signature colour, Public Sans + JetBrains Mono typography (bundled, no external font loading), and consistent metric cards, badges, alert banners and buttons across all 8 tabs. The **History** table drops its old plain-black header in favour of the same light header used everywhere else. This is a **presentation-only** change: every tab keeps the exact same content, navigation and interactions as before — nothing to relearn. A dark theme is structurally prepared but **not enabled** in this release.

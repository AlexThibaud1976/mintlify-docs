TestPulse Studio is a free extension of the Visual Studio Marketplace. It is private for now: it is shared with the organisations it is meant for and does not show in a Marketplace search.

## From the Marketplace {#marketplace-install}

1. Open the extension's page from the link you were given, or from **Organization settings › Extensions › Shared**
2. Click **Get it free**
3. Select your **organisation**
4. Click **Install** and accept the permission scopes
5. Open any project: the **TestPulse Studio** group appears in the project navigation, with its four areas **Insights**, **Coverage**, **Design** and **Tools**

## On-premise (.vsix) {#onprem-install}

1. Open the extension's page from the link you were given, click **Get it free**, then **Download** (offered for Azure DevOps Server) to get the `.vsix`
2. Go to **Collection Settings → Extensions → Manage Extensions**
3. Click **Upload extension** and select the `.vsix` file
4. Click **Install** to make it available in all projects

## Prerequisites {#prerequisites}

| Requirement | Details |
| --- | --- |
| Azure DevOps version | Azure DevOps Services (cloud). Azure DevOps Server 2022.1: verification in progress (the extension installs on Server) |
| Browser | Chrome, Edge or Firefox with JavaScript enabled |
| Permissions | Member of a project with at least one Test Plan |
| Admin (install only) | Organisation admin to install extensions |
